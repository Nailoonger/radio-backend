# 小程序底部导航水滴动效 Spec

## 背景
用户端已有首页、投稿、风采、我的四个 Tab，以及浮动底栏和选中胶囊。当前胶囊只作平移。本次将切换升级为水滴流动和轻微弹簧回弹。

## 目标
四个 Tab 切换时，胶囊、图标、文字与目标页内容共同完成约 400ms 的动效。

## 功能需求
- F1：保留四个 Tab 的名称、顺序、路由及当前底栏配色与尺寸；点按其他 Tab 后立即切页，由目标页显示一次从来源位置到目标位置的胶囊动画。
- F2：胶囊前沿先向目标移动，后沿稍后跟随；中途沿移动方向拉长并略微变扁，末尾轻微越过终点后回弹停稳。左右切换与跨多个 Tab 均按实际距离和方向表现。
- F3：新选中图标先缩小再弹回原尺寸，文字颜色平滑过渡到选中色；原选中项退回未选中态。
- F4：目标页内容从点击方向一侧轻移入场，同时淡入；向右切换从右侧进入，向左切换从左侧进入。导航栏自身不随内容移动。
- F5：初次进入、不产生 Tab 切换的页面重显、重复点击当前 Tab 均不播放切换动画；快速连续切换后，最终路由、选中态和胶囊位置一致。
- F6：首页启动遮罩与底栏显隐继续遵循现有行为，不出现底栏闪现。

## 非功能需求
<!-- review-fix: S9-duration -->
- N1：胶囊、图标和页面入场动效统一设为 400ms，文字颜色过渡不超过 400ms；后沿延迟和形变幅度在技术计划中给出具体数值。
- N2：使用微信原生小程序能力，不增加运行时依赖；动画不改变页面布局、滚动位置和表单内容。

## 不做的事
不增加 Tab，不改页面业务功能，不实现手势滑动切页，不改管理后台，不引入装饰渐变或彩色阴影。

## 验收标准
- AC1（F1）：逐一点击四个 Tab，路由立即响应，每次仅在目标页观察到一次从来源位置出发的动画，底栏外观保持原样。
- AC2（F2）：分别执行相邻左右切换、首尾跨格切换；逐帧观察到前沿先行、后沿跟随、拉长变扁、轻微回弹及最终居中。
- AC3（F3）：切换时观察目标图标缩小后回弹、文字颜色平滑变化，原图标和文字恢复默认状态。
- AC4（F4）：左右切换时，目标页从对应方向轻推淡入，底栏固定且页面无布局跳动。
- AC5（F5）：冷启动、重复点击当前 Tab、进入详情再返回不误播；400ms 内连续点击不同 Tab 后最终路由与选中位置一致。
- AC6（F6）：冷启动首页期间底栏隐藏，遮罩退场后底栏正常滑入，无闪现。
- AC7（N1、N2）：在开发者工具检查胶囊、图标和页面入场动效配置为 400ms，切换前后滚动与表单状态符合现有页面行为，无新增依赖。
