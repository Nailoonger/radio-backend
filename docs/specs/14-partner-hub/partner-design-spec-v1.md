1. **不要深色，任何形式**（点名三次）。✅白卡 + 深色字 + 羊皮纸底。
2. **手机里不要装饰性描边框**；留描边 = 有状态含义（已选 / focus / 缺岗）。
3. 无渐变、无彩色投影；演示标注一律加在手机外。
4. 胶囊不是一律药丸：**网格 12px、横带 8px、按钮 13px，只有状态标签是药丸**。
5. UI 参数先量原型，不猜。

## 三、结构口径：入口放哪，原型说了算

> v111 注释原文：「值班时段 / 草稿调整 已经并进**排班工作台**一页，这里不再重复收入口」。
> v136：「代录入口只在排班工作台里，班表首页不再重复」。

| 页 | 该有什么 | 不该有什么 |
|---|---|---|
| **班表页**（scheduling） | 状态条 + 本周班表卡 + 主按钮 + **四行**（工作台/轮值/发布记录/导出）+ 权重说明 | ❌ 值班时段、排班规则、代录的入口（我加的两行要撤） |
| **排班工作台**（planning） | 状态条 + 班表区 + 操作区 + **四行子模块**：`值班时段`／`排班规则`／`值班时间代录`／`发布与调整记录` | ❌ 三步流程卡（我做的三步是自造，要对齐原型） |
| **工作台管理区**（desk） | 三张卡：账号 / 排班规则 / 考勤总览 | ❌ 值班时段卡（我加的要撤） |

**排班工作台操作区（按状态给按钮）**——原句：

- `none / withdrawn`：时段已发布 → `生成班表草稿`；没发布 → 超管 `去发布值班时段`，社干 `查看时段准备情况`
- `draft`：三个等宽 `再次生成` ／ `检查班表` ／ `确认发布`，下面小字 `一键清空班表（清掉所有人员，重新生成）`
- `published`：`撤回发布` ／ `建立修订草稿`，下面小字 `我的班表（本人在正式版里的位置）`

**工作台状态条（原句）**：`已发布 v{N} · 站员已能看到本周班表`；`草稿 未发布 · 还有 {N} 个岗位空缺，补齐并校验后才能发布`／`已排齐，校验后可发布`；`已撤回 等待重新发布 · 历史版本在「发布与调整记录」里`（超管）；`本周未排班 时段已发布，可以生成草稿`／`值班时段还没发布`。

**空态不删表（v111）**：没有班表也要留整周表格，格子里显示「空缺」，**不能给一张空态卡把表删掉**。 withdrawn 的提示：`班表已撤回，下面是整周待排的时段；生成或调整后再发布。`；none：`本周还没生成班表。下面是已发布的时段，格子里都空着——生成草稿就会自动填人。`

## 四、以前拍板的逻辑（照办，不再讨论）

1. **早会横带固定存在**：无论有没有数据都渲染这条「早会」带（陛下 2026-10-29 定）。
2. **单日时段 → 横带；多日时段 → 网格**；横带胶囊只写名字。
3. **缺岗不硬凑**：硬约束（可排/请假/上限）优先，凑不齐就留缺岗。
4. **班表管理＝只读**（v118）：所有编辑（生成/换人/校验/发布/清空/撤回）只在排班工作台。
5. **首页直接给本周班表**（v112），不用点进去才看得到。
6. **请假只改状态不动班表**；批准后那格空出来是生成时按已批请假过滤的结果。
7. **互评匿名聚合**：永不返回评价人；后台不做谁评谁明细。
8. **站员 = 学生身份的第二角色**（`admin.userId → user.id`），不是第三种人；一人一套密码。
9. **值班时段/排班规则只有超管能改**；社干和站员进去是只读（原型 note 原文）。
10. **发布后可撤回**；撤回历史只有超管在「发布与调整记录」看得到。

## 五、错误提示口径（这两天踩出来的）

1. **「拉不到」≠「没数据」**：接口失败必须红条 `数据没拉到` + 真因，**不许伪装成空态**。
2. 真因取云函数 `data.error`（已改 schedule/index 的 catch）；稳定前不撤。
3. 提示只出现在**接口真的失败**时；正常流程里不塞「稍后重试」类的话术。
4. 锦上添花的请求（副标题、角标）必须 `.catch` 兜底，**不能把整页拖成报错**。

## 八、值班时段配置屏（timeslots · 2026-10-29 陛下补图定稿）

> 原型源：`_cmpA.html` 的 `timeslots` 屏 + `slotCards()` + `slotNewSheet()`。
> **卡片 = 一个「场次」**（名称+起止+哪几天+部门×人数），不是逐天逐部门的表格行。
> 后端 `templates` 仍逐行存储（day×dept），前端聚合/展开，存储不动。

### 卡列表（原句）

- 空态：`还没有值班时段。点上面「＋ 新增值班时段」加一条。`
- 卡结构：`{名称}` + `{N} 天` 圆标 + `编辑`/`删除` → `{周一 19 日、周二 20 日 …}` → **大字时间** `{06:50}—{07:30}` → 分隔线 → `{N} 个部门每场共 {N} 人` → 明细行 `{部门}-{岗位}` ／ `每场 {N} 人`
- 部门→岗位映射：播音部→播音、主持部→主持、编辑部→编辑
- 删除二步确认：`删掉「{名称}」这个时段？站员端也会同步消失。` + `取消`/`确认删除`
- 明细行连接符用 `-`（以陛下截图为准，不是原型代码里的 `·`）

### 顶部与发布（原句）

- 顶部：`第 {N} 周 {MM/DD} – {MM/DD}` + 右侧标签 `草稿未发布`／`已发布`
- 说明：`每天各自设：哪天有几场、叫什么、几点到几点。发布后站员才能填可排时间。`
- 主按钮：`＋ 新增值班时段`
- 发布条：`发布本周值班时段` + 说明 `发布要填原因（记进发布记录）；发布前站员看不到、也填不了可排时间。`

### 加/编辑弹层（原句）

- 标题：新建 `加一个值班时段`；编辑 `编辑值班时段`
- 说明：新建 `选哪天、叫什么、几点到几点；再勾上这一场需要哪几个部门、各要几个人。`；编辑 `改完点「保存修改」，这一周的时段和站员端同步更新。`
- 段落标签：`星期几（可多选）`／`时段名称`（placeholder `比如：午间 / 傍晚 / 例会`，≤6 字）／`起止时间`／`部门与人数（0 = 这个部门不参与）`
- 部门顺序：主持部、播音部、编辑部（原型表单顺序）；± 步进，0 = 不参与
- 底部：`取消`／`保存时段`（编辑时 `保存修改`）

### 量值补遗（2026-10-29 下午第二轮，app.html 实测）

**四行大白卡（planning）**：`.pl-list` 白卡 radius 20px + **1px #E8E9EF 描边** + 投影 `0 5px 20px rgba(32,36,49,.03)`、卡内无水平 padding；`.pl-row` **高 62px**、padding 12/16、gap 12px、fs 14px、行间**无分隔线**；`.st` fs 11px `#76767E`；`.ar` fs 16px `#C7C7CC`。

**加/编辑弹层**：`.sn-body` radius 22px 顶部；`.sn-hd b` **20px/600 独立行**、`.sn-hd p` 12.5px 独立行（**标题和说明不许挤一段**）；`.sn-days button` h 44px radius 12px **白底描边**，选中 `--tint` 底 + 蓝描边 + 蓝字 + 600；`.sn-inp` h 44px radius 12px 描边；`.sn-times` 时间块白底描边、时间居左、右侧描边圆圈时钟；`.sn-dept .cnt` **整体 1px 描边 radius 10px、内部 −/数字/＋ 三格白底、数字格两侧 1px 分隔**；`.sn-btn` h 46px radius 12px，取消 = `#F4F4F6` 底描边**蓝字**。

**场次卡**：`.slot-card` 白底 + 1px #E8E9EF + radius **22px** + padding 18/16/14；`.hd b` **20px/600** flex:1；`.tm` **26px**、分隔符 `—` 同字号 muted 色（所以显长）；`.hr` margin 14/12。

**口径修正（推翻前文）**：
1. 原型 `.pl-ops .btn` = **13px 方角**（实测 br 13px），不是药丸 —— 全宽主按钮也是方胶囊
2. **空态（时段已发布、班表未生成）只显示「本周班表尚未生成」一句**，不铺整周空表
3. **次级页面（值班时段等）不挂底部导航**，只有四个 tab 页挂 dock
4. 「每场 N 人」= **单场配置**，同部门跨天不累加
5. 弹层 input **不做受控 setData**（键盘竞态会吞字、保存拿旧值），打开时设初值、输入记实例、保存读实例

### 技术注记

- 后端 `_kit.normalizeTemplates` **已支持同 day+同 title+同时间的多部门条目**（parallel 且 dept/role 不同 → 放行），无需改存储；不同名称的时间重叠仍然报错。
- 前端聚合 key = `名称|起|止`；展开时按 `天 × 部门(count>0)` 生成行，role 取映射表。
