# 伙伴端登录页 v54

此版桌面网站布局已因用户明确纠正而作废，由 ../login-v55/spec.md 的原生小程序方案替代。

延续现有手机端交互原型，新增一个可直接打开的伙伴端登录页。用户明确指定 `微信图片_20261022142229_296_6.png` 为背景；项目现有 assets/profile-campus-garden.png 与该原图 SHA256 一致，直接复用，不重绘、不压缩。

- F1：手机端以校园水彩图作为上半屏主背景，保留凉亭与桥的辨识度，白色登录浮层从背景下方叠入；电脑端使用同一背景与靠右的登录浮层。字体沿用菁悠字体栈，唯一交互强调色 #0066CC，中性阴影，不使用装饰渐变。页面标明菁悠广播站、伙伴端和站点口号。
- F2：提供伙伴账号、密码、显示／隐藏密码、登录、演示账号选择和登录帮助。空值及未知演示凭据就地报错；Enter 可提交，错误关联对应输入，焦点可见，触区至少 44px。演示账号选择后填入虚构账号与密码，站员、社干、超管各一项。
- F3：当前为独立交互原型，明确标示演示身份体验。只接受固定演示凭据，成功后沿用现有 store.setRole 切换演示身份并进入对应首页，保留已有所有业务资料；不收集或持久化密码，不生成正式 token，不新增真实登录接口。存储失败就地提示并保留输入，不跳转。帮助说明账号由站内管理员开通及当前原型的演示入口。
- F4：新增 login.html 独立入口，并在现有原型外侧控制区提供“伙伴端登录”链接。原班表、工作台及其他页面不受新布局样式影响。

验收：320px、390px 及桌面宽度下背景可辨认、输入和按钮完整、无横向溢出；键盘弹出或矮屏允许自然滚动。实际验证空表单、密码显隐、演示选择、错误凭据、成功跳转及帮助展开；用隔离存储验证三种身份、失败不跳转及业务资料保留，实际浏览器不清空原资料。最终提供可访问本机链接与截图。
