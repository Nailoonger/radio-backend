# 风采展示（成员展示）Spec

## 背景

菁悠广播站已运行多年，社团有一批长期在岗的主播、技术员、编辑同学。
现有小程序只有节目/公告/投稿，没有专门展示团队成员的板块。
希望新增「风采展示」模块，让小程序用户能看到「广播站里都有谁、各自负责什么」，增强社团归属感与对外宣传。

## 目标

- 让小程序用户能查看所有「展示中」的广播站成员，按职务分组浏览
- 让超管在管理后台维护成员档案（CRUD + 头像上传 + 上下架）
- 模块独立、低耦合，不影响现有的节目/投稿/公告流程

## 功能需求

### F1：成员数据模型
- F1.1 字段：姓名、职务、年级班级、栏目（多文本，逗号分隔）、头像、座右铭、排序权重、是否展示
- F1.2 字段长度约束：姓名 ≤ 32 字、职务 ≤ 32 字、年级班级 ≤ 32 字、栏目 ≤ 200 字、座右铭 ≤ 200 字
- F1.3 头像：URL 字符串，必填
- F1.4 排序权重：整数，默认 0，数值大者靠前
- F1.5 是否展示：1=展示 0=隐藏，默认 1
- F1.6 软删除：不在模型层做（业务层过滤 `isShow=0` 即可，无须真删）

### F2：管理端 CRUD（仅超管可访问）
- F2.1 列表：分页、按姓名/职务/年级模糊搜索、按职务筛选
- F2.2 新增：填写上述字段，可选上传头像
- F2.3 编辑：所有字段可改
- F2.4 删除：硬删除（不做软删）
- F2.5 切换展示 / 隐藏：与 F2.3 同行内联按钮
- F2.6 头像上传：接受 jpg/png/jpeg/webp，单文件 ≤ 2MB

### F3：用户端展示
- F3.1 「风采展示」tab：底部 4 个 tab（第 4 个）
- F3.2 进入后：按职务分组的 tab 横向切换（社长 / 主播 / 编辑 / 技术员 / 全部）
- F3.3 列表卡片：圆形头像、姓名、职务、年级班级
- F3.4 详情页（点卡片进）：头像、姓名、职务、年级、栏目、座右铭
- F3.5 仅展示 `isShow=1` 的成员；后端已过滤，前端无需处理

### F4：头像上传
- F4.1 接口：POST `/api/admin/upload/avatar`
- F4.2 入参：multipart/form-data，字段名 `file`
- F4.3 校验：MIME 类型必须是 image/jpeg|png|webp；size ≤ 2MB
- F4.4 存储：写入 `./uploads/avatars/yyyy-mm/<random>.<ext>`
- F4.5 返回：`{ url: '/uploads/avatars/...', filename }`
- F4.6 Express 静态目录挂载 `/uploads` 到 `./uploads`

### F5：导航入口
- F5.1 管理后台：侧栏新增「风采展示」菜单项（超管专属）
- F5.2 小程序：tabBar 第 4 项 `pages/members/members`，icon 使用现有「我的」图标先复用、文案「风采」

## 非功能需求

- N1：列表接口响应时间 ≤ 50ms（SQLite 单表 < 100 行）
- N2：头像目录自动按月归档，避免单目录文件数过多
- N3：上传失败有明确错误提示（类型不符 / 太大）
- N4：所有写接口必须经 `adminAuth` + `requireSuperAdmin` 校验
- N5：所有读接口（小程序）公开，无须登录
- N6：列表接口返回时排除 `password` 等敏感字段（本模块无密码字段）

## 不做的事

- 不做头像裁剪/压缩（前端直接传原图）
- 不做成员登录或登录态关联（成员是展示用，不进 admin 表）
- 不做留言二级回复、点赞、收藏
- 不做成员 ↔ 节目的多对多关联（栏目是文本字段）
- 不做软删除（用 isShow=0 实现「下架」即可，硬删留给管理端按钮）
- 不做头像 CDN / 远程存储（本地够用，迁移时打包整个 uploads/）

## 验收标准

- AC1：管理后台菜单侧栏出现「风采展示」，点击进入列表页，超管可见，社员不可见
- AC2：新增一个成员（填姓名、职务、年级、上传头像），刷新管理端列表能看到
- AC3：管理端搜索「社长」返回职务包含「社长」的成员
- AC4：上传 5MB 头像被拒绝（提示文件过大）
- AC5：上传 txt 文件被拒绝（提示类型不符）
- AC6：小程序 tab 第 4 项「风采」可点击进入，展示所有 isShow=1 的成员
- AC7：职务 tab「社长」只显示职务为社长的成员
- AC8：点成员卡片进入详情页，能看到头像 + 所有字段
- AC9：管理端将成员切到 isShow=0 后，小程序列表立即不再显示该成员
- AC10：访问 `/uploads/avatars/xxx.jpg` 能直接看到图片（200）
