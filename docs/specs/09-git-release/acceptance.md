## 首次启用的外部步骤

按 [启用说明](../../git-release.md) 配置两项必需 Secret 和三项 Variable，关闭重复发布入口。推送代码后手动运行 `check`，通过后运行 `publish` 初始化两端成功基线，再确认原网址、登录、子页面刷新和云函数配置。

密钥直接保存在 GitHub Secrets，不需要发到聊天。之后 `master` 推送会按组件更新；小程序正式上传、审核和上线继续使用微信流程。
