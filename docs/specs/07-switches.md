# 模块开关 Spec

## 背景

菁悠广播站现有 4 个用户可交互模块（点歌、文稿、留言、风采展示），但缺少运营开关——例如：
- 投稿高峰期需要临时关闭新投稿避免积压审核
- 留言板出现违规内容需要紧急关闭
- 风采展示资料未到位时希望先下架

现状只能靠超管"删数据"或"逐条审批"绕过，笨拙且有副作用。

需要一个轻量模块开关系统，超管可在管理后台一键启停任意模块，学生端实时看到效果。

## 目标

- 提供 4 个模块的独立开关：点歌、文稿、留言、风采展示
- 超管通过侧栏独立菜单「模块开关」集中管理
- 默认全部开启；改一处即生效，无需重启
- 用户端入口保留但提交时给友好提示「该模块暂时关闭」

## 功能需求

### F1：数据模型
- F1.1 新建表 `system_switch`，字段：id, key, value, desc, updatedAt, updatedBy
- F1.2 `key` 唯一，varchar(64)
- F1.3 `value` 字符串，约定存 `'on'` 或 `'off'`（便于未来扩展三态）
- F1.4 `updatedBy` 关联 admin.id
- F1.5 启动时若表为空，自动 seed 4 条默认记录（全部 on）

### F2：管理端
- F2.1 侧栏新增菜单「模块开关」（超管专属）
- F2.2 列表展示 4 个模块（中文名 + key + 当前状态 + 最后修改人 + 时间）
- F2.3 一键切换：el-switch 切换 on/off，立刻保存
- F2.4 提供 GET `/api/admin/switch/list` + PUT `/api/admin/switch/:key`
- F2.5 切换需要超管权限，操作记日志（更新人 + 时间）

### F3：用户端接口
- F3.1 提供 GET `/api/user/switch/list`（公开），返回当前 4 个开关状态
- F3.2 提供 GET `/api/user/switch/:key`（公开），返回单个开关状态
- F3.3 开关键值约定：`submit_song` / `submit_article` / `message` / `member`

### F4：后端拦截
- F4.1 POST `/api/user/submit` 提交时，根据 type 判断走点歌 or 文稿；任一关闭则抛 `403 模块已关闭`
- F4.2 POST `/api/user/message` 留言时，关闭则抛 `403 模块已关闭`
- F4.3 列表接口（`/api/user/member/list` 等）**不拦截**，仅拦截写入接口
- F4.4 错误码：新增 `MODULE_DISABLED = 40302`

### F5：小程序端
- F5.1 进入小程序时拉取一次 `/api/user/switch/list`，存到 app.globalData
- F5.2 投稿页 type tab：被禁用的类型置灰、点提示「该模块已关闭」
- F5.3 提交时如失败错误码 40302，弹 toast「该模块暂时关闭，请稍后再试」
- F5.4 风采 tab：disabled 时 tabBar 图标变灰、文案加「（暂停）」

### F6：管理后台 Swagger
- F6.1 补 Switch schema + 「模块开关」tag
- F6.2 admin/user 路由加 @swagger 注解

## 非功能需求

- N1：开关切换后 30 秒内全端生效（小程序端靠下拉刷新 / 下次进入触发）
- N2：开关读取走 30 秒内存缓存（避免每次提交都查 DB）
- N3：所有写接口（admin 切换 / 用户提交）必须鉴权
- N4：开关状态返回结构简单，体积小，便于缓存

## 不做的事

- 不做开关历史记录（审计）—— 暂只存最新值 + 修改人 + 时间
- 不做按时间段自动启停（cron 任务）—— 暂只手动
- 不做多租户/多站点隔离 —— 单站点
- 不在开关界面里加权限细分 —— 只要是超管就能改
- 不做开关值校验白名单（任何字符串都接受）—— 内部约定 on/off 即可
- 不改留言展示（只控写入；老留言继续展示）—— 临时关闭不影响已展示内容

## 验收标准

- AC1：管理后台侧栏出现「模块开关」，超管可见，社员不可见
- AC2：首次启动自动 seed 4 条默认记录（全部 on）
- AC3：管理后台能切换任一开关到 off，状态立即更新（前端响应）
- AC4：切换后 GET `/api/user/switch/list` 返回对应 off
- AC5：点歌关闭后，POST `/api/user/submit {type:1}` 返回 40302 模块已关闭
- AC6：文稿关闭后，POST `/api/user/submit {type:2}` 返回 40302 模块已关闭
- AC7：留言关闭后，POST `/api/user/message` 返回 40302 模块已关闭
- AC8：风采关闭后，GET `/api/user/member/list` 仍返回（不拦截读）；后续若有写入接口才拦截
- AC9：小程序首次进入拉取一次开关存在 app.globalData
- AC10：被禁用的 tab 在小程序上变灰、点击提示已关闭
- AC11：恢复开关到 on 后，所有接口立即可用（缓存 30s 内可能延迟）
