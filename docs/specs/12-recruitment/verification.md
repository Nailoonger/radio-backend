# 招新模块实现与验证记录

日期：2026-10-02（北京时间）。已实现，未部署。

## 完成功能

「我的」公开加入我们入口；三页报名/查询流程；四项自填必填信息；后台四种题型配置与排序；随机查询码复制、截止前修改/撤回/原码重新提交；管理员审核、面试安排、内部备注、拟定结果及撤销；超管统一发布和历史归档。

公开接口不要求学生账号，所有可见性、时间窗口、去重、事务和管理员权限在云服务端校验。查询码只内存使用或由学生复制保存，不放导航参数及日志；首次提交响应丢失可用暂存的原请求凭证重试。

## 实际验证

- 云端回归：源码与单文件打包产物合计 **3415 项，失败 0 项**。其中招新业务每轮 126 项，覆盖 AC1～AC11 的接口行为；前端门面 17 项、初始化隔离和权限验证 8 项。
- Web 后台：`npm run build` 通过，含 Vue 模板编译和新路由构建。
- 小程序：用已安装微信开发者工具的 `wcc.exe` 编译三份新页及「我的」WXML，`wcsc.exe` 编译相关 WXSS 与 app.wxss，通过；相关页面、工具、组件及管理子包共 26 份 JS 的 `node --check` 通过。
- `git diff --check` 通过；用户原有工作区改动保留。
- 仓库要求的 Jest 已运行：6 套件，41 个通过、15 个失败，失败在旧 member/switch 套件；本次未修改原 Express 业务代码。已观察到旧 member 路由返回 404，不能把全量 Jest 报为全绿。
- 独立代码复查发现原生云调用伪造 HTTP 来源逃逸限流，已修复为平台 OPENID 优先；同一平台身份连续改变伪造 IP，第 21 次查询仍被限流的测试已加入。
