# 开声 · 登录概念资产

[两态效果图](concept.png) · [内置 image_gen 生成提示词](generation-prompt.txt)

设计概念：一条声线连接问候语和登录表单，验证通过后收束为姓名首字头像，让登录与首次改密形成连续的视觉过程。效果图展示静态关键状态，动效尚未实现。

原创细线 SVG，画布统一为 320 × 96，描边为 1.7px 圆端线条。强调色 `#0066CC`，辅助线色 `#C7CCD3`。文件不含文字图形、姓名、动画、脚本或外部资源。

- `icons/idle.svg`：输入时只给予轻柔的视觉回应，中央保持短小的蓝色起伏。
- `icons/verifying.svg`：提交后、真实账号验证尚未完成时使用连续蓝色声波。
- `icons/welcomed.svg`：仅在真实认证成功后转为欢迎态。蓝色空心圆可由应用层填入当前学生的姓名首字，SVG 自身不预置身份。

波形不表示密码长度、强度或评分，也不表示开启麦克风或正在录音。本目录仅为设计资产，未接入应用。
