值班时间代录 · 默认周改成「下一周」 v1

陛下原话：「可排时间存哪一周，当然是本周填下一周的啊」。所以这页默认打开的那一周， 从本周改成了下一周；胶囊也随之改口径 —— 照抄「本周 / 非本周」会把默认页标成「非本周」， 看着像进错了页面。下面三段是同一个切换条的三种状态，颜色、字号、间距全部照搬 availability.wxss 里的 .wk-nav 一套。

为什么必须改、以及为什么要后端给锚点

  • 不改会白填：下周班表（schedule.generate）读的是下周那份可排时间 （DUTY_AVAILABILITY{weekStart = 被排的那一周}）。默认落在本周，站员填完、 下周生成时读不到 → 所有人都「未确认该时段可排时间」，只能靠超管逐人代录。
  • 前端不算周一：默认周一律由云函数给（thisWeekStart / nextWeekStart 一起回）， 手机自己算在跨时区、跨月、系统时间被改过时会差一周，而班表错一周是无声的 —— 界面不会报错。
  • 其它页不受影响：请假、考勤、排班工作台、我的班表仍然是「本周 / 非本周」那套； 只有这一页换成「下一周」口径，校验脚本按页分两种口径各查各的。
  • 还没做：「周一 0 点到周六 24 点才能填、周日整页只读（超管可代录）」这条硬拦截不在本版， 要和「周日 0 点切下周」一起单独做一轮，因为会连带请假 / 考勤 / 工作台的「本周」口径。
