学生账号模块 · 目录化重构

现在这个模块是一个页面 + 4 个平级页签 + 2 个隐形页签。但它管理的对象本来是四层： 批次 → 年级 → 班级 → 账号。层级被压平成「两个下拉框 + 一组页签」， 所以「主目录（年级）」和「子目录（班级）」混在一起，既看不出父子，也回不到上一级。 本方案把平级页签换成一棵目录树 + 一块工作区：唯一的状态源是「树上选中了哪个节点」， 并把位置写进 URL。设计系统完全沿用 v8，不新增任何组件。

一、五条病灶（每条都能在现有代码里指出位置）

1
「页签」这一个变量同时表示两件事 → 主目录和子目录打架
tab 既表示「我在哪个平行功能」，又表示「我在按年级里的哪一层」。 switchTab('grades') 会顺手把 gradeInfo=null（退回一级）， 而 openGrade() 又把 tab 原地设回 'grades'。 结果「返回上一级」靠的不是导航，是手写的一行 ‹ 返回按年级总览。
2
班级下拉的选项，取决于你「上一次打开过哪个年级详情」
classOptions 的来源是 gradeInfo.value?.classes。 没进过任何年级详情 → 班级下拉是空的；进过 2023 级再去查 2024 级 → 班级选项还是 2023 级的班。 子目录挂在「上次访问痕迹」上，而不是挂在主目录上 —— 这是最关键的一处逻辑倒挂。
3
两个「隐形页签」：年级详情和清理回执
年级详情由 gradeInfo 非空抢渲染，清理回执走 tab === 'receipt' —— 但 receipt 根本不在 tabs 数组里，所以进到回执时页签条上一个高亮都没有， 随手点任何页签都会丢掉它。它们是第三、第四层，却被渲染在第一层的画布上。
4
没有位置感：刷新、后退、分享全部失效
全部层级共用一个 URL /student。刷新回到总览；浏览器后退不生效； 想把「2023 级 01 班」给同事看一眼只能口头描述。而项目里已经有先例 —— 点歌设置就是独立子路由 submit/settings。
5
同一个动作两套入口、两套语义
批量重置密码：工具栏弹窗走 PUT /student/reset-password（按年级 / 班级范围）， 批量条走 POST /student/reset-password/batch（按勾选的 ids），确认文案还不一样。 另外「导出本届 xlsx」会偷偷改写 listQuery.grade； 导入完成回执 importResult 切走再回来还挂着上一次的。

二、新逻辑：一棵树，一块工作区

把「平行页签」换成「父子目录」。层级一次性写死，界面上不再出现第二种选择方式：
对象层级（数据本来的样子）
批次 （一次导入动作 · 跨年级） └ 年级 ← 主目录 └ 班级 ← 子目录 └ 学生账号 ← 叶子 横切：毕业清理 （动作，挂在年级上） 清理回执 （历史，挂在年级下）
左侧目录树（唯一状态源）
▸ 全部账号 1,284 ▾ 在用年级 ▾ 2023 级 ● 312 ← 可毕业清理 01 班 45 02 班 44 … ▸ 2024 级 330 ▸ 2025 级 321 ▾ 已归档 2022 级 已清理 ───────────────────────────────── 名册导入 ← 动作，进向导 导入批次 ← 动作，跨年级
右侧工作区只由当前选中的节点决定，没有第二个开关。四种节点视图： 全部账号 / 年级节点 / 班级节点 / 归档节点；两个动作：名册导入向导、导入批次。 动作做完回到来的地方。

刷新、浏览器后退、把链接发给同事 —— 三件事同时恢复。目录树上的高亮和面包屑都由 URL 反推， 不另存一份状态（这也顺手消掉了病灶 1）。

四、两条路线，请挑一条

A · 目录化（本预览）
左侧目录树 + 右侧工作区，年级 / 班级是父子节点，唯一状态源是树上的选中项，全部 URL 化。
改动：StudentAccounts.vue 拆成 1 个壳 + 5 个子视图； router/index.js 加 4 条子路由。后端 0 改动。
解决：病灶 1~5 全部。
B · 轻量修正（保留页签）
页签仍是 4 个，但年级详情与回执改为 URL 驱动（?grade= / ?view=receipt）， 页签条保持「按年级」高亮；班级下拉改成「先选年级才可用」的级联，不再读上次的详情。
改动：约原文件的 1/3，不拆文件。后端 0 改动。
解决：病灶 1 / 3 / 4 / 5；病灶 2 只是缓解 —— 年级和班级仍然是两个下拉框，平坦感还在。
我的建议是 A。问题的根子是「层级被摊平」，B 保留了摊平的前提，只能打补丁。 而且 A 的前端改动量并没有想象中大：现有 6 个视图的 DOM 和逻辑几乎可以整段搬进子视图组件， 真正新写的只有目录树和路由。

五、改动清单

前端 · 拆views/StudentAccounts.vue → views/student/ 下： StudentIndex.vue（壳 + 路由出口）、StudentTree.vue（目录树组件）、 NodeAll.vue、NodeGrade.vue、NodeClass.vue、 NodeArchive.vue、ImportWizard.vue、Batches.vue。
前端 · 路由router/index.js 在已有的 student 下挂 4 条子路由， 与现成的 submit/settings 同一种写法。
前端 · 顺手修① 班级筛选改由树提供，不再读 gradeInfo； ② 批量重置只留一个入口，跟随当前范围（勾选 → 按 ids，未勾选 → 按节点范围），按钮文案随之变； ③ 导出跟随当前节点，不再改写 listQuery.grade； ④ 导入回执只在向导内出现，离开即清。
后端0 改动。现有接口刚好够：/student/list?grade&classNo、 /student/grades、/student/grade/:grade、 /student/cleanup/last?grade=、/student/batches。 唯一可选新增：GET /api/admin/student/tree（一次返回年级 → 班级 → 人数整棵树）， 否则左树要发 1 + N 次请求拼接。不加也能跑，只是年级多时请求数线性涨。
不动的所有接口路径与权限（整块仍是 requireSuperAdmin）、 清理三模式（safe / disable / purge）、导入识别的三段规则、v8 设计系统、侧栏 （/student 前缀已能高亮，MainLayout.vue 一行不用改）。
