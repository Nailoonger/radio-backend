方案 v1「主控单元」——把管理端登录做成一次开机对轨PREVIEW v1

  • 为什么是这个隐喻：学生是「听广播 / 点歌的人」，管理员是「控制广播的人」。所以学生端用接收侧的物件（收听证、唱盘、调频），管理端用播出侧的物件——主控单元面板。换成别的 App 不成立。
  • 账号 = 写入通道标签：账号不是填进输入框，而是被「标签机」实时打进一条胶带上（全程两侧齿孔、两端斜切撕口），就像通道条上贴的那张手写名签。
  • 密码 = 推子行程：密码长度驱动物理推子从 -∞ 推向 0dB，红色推子帽越往上，面板右侧电平越高；不是常见的"密码强度条"那种通用组件。
  • 提交按钮 = 推钮本身：按钮不是一个孤立的 CTA，而是面板上的一枚大推钮，文案随状态变：待机 → 等待密钥 → 推入播出总线（解禁，红色呼吸）→ 认证失败 → ON AIR。没满足条件时它真的按不下去。
  • 三颗状态灯：POWER（琥珀常亮，机器已上电）/ ID（绿，账号就位）/ ON AIR（红，推到位）。错误时 ID 与 ON AIR 快闪三下——对应真实调音台的 rejected 反馈。
  • 底部两个只有广播站才有的信息：北京时间 LED 窗 + 今日播出时段与轮值部门。把"登录页很空"这件事交给真实业务信息填充，而不是放插画。
  • 记住账号 = 面板拨动开关（金属拨钮 + 蚀刻 OFF/ON），不是浏览器 checkbox。
