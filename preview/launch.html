「声波唤醒」启动动画

灵感直接来自站徽本身——徽标中心就是一组声波条纹。动画让这组声波从徽标里"醒过来"：徽标弹入 → 站名五字逐字浮出 → 底部声波从中间向两侧依次竖起，随后转入持续律动。那一团律动的声波同时就是加载态：数据没到就一直在动，数据到了整层淡出交给首页。全程 1.7s，循环演示 6.4s。

0.10s徽标弹入（过冲到 1.05 再回落） 0.36s站名五字逐字上浮，每字间隔 70ms 0.62s声波 11 根，由中心向两侧竖起，每根间隔 45ms 1.10s副标题淡入 1.35s底部说明淡入 1.70s整层淡出并轻微推近，首页接管
0.00s 拖动时间轴可逐帧看节奏

落地到小程序要注意的五件事

  1. 微信的启动画面无法自定义。所以这个动效不是「启动图」，而是首页上的一个全屏覆盖层：首页 wxml 最外面包一层 <view class="launch-mask">，进来就播 1.7s 入场；wx.request 回来后再整层淡出。
  2. 声波统一当加载态用，而不是固定等 1.7s。数据先到 → 立刻淡出，不拖沓；数据后到 → 动画播完停在律动态继续转，避免出现白屏。节奏用 animationend 或 setTimeout 兜底。
  3. 数值单位换 rpx。本页按 390pt 设计：站徽 96 → 192rpx，站名 22 → 44rpx，声波条 4×27 → 8×54rpx，间距 5 → 10rpx，底部停靠 148 → 296rpx。动效时长不变。
  4. 首页本身的进场不要在遮罩下做，否则用户看不见。建议遮罩淡出时首页只做 scale .985 → 1 的轻微推近（本页已示范），不要再叠别的动画。
  5. 深色场景用单色版徽标，不是原图。原图是彩色双色（藏蓝 #083090 + 中蓝 #2090D0），直接放深底上会糊掉。已由原图灰度重映射生成 preview/assets/station-badge-mono.png：环字与文字 → #FFFFFF，声波条 → #969696，透明度逐像素保留。深色场景一律引这张。
  6. 顺便该把小程序里的徽标素材换掉。现在用的是 miniprogram/assets/station-logo.jpg（白底 JPG，63 KB）；新素材是透明底 PNG（1410×1410，103 KB），且与后台 admin-web/public/station-badge.png 是同一张。切口干净，顺带解决首页头部徽标带白方块的问题。
