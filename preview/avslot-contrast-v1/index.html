改之前

未点亮的方块 完全没有边界：那块灰和页面底色是同一个色值，描边又是透明的， 看起来就是页面上飘着两行灰字。

改之后

未点亮是 白底 + 灰描边（原型 v151 的原始形态），方块边界一眼看得见；点亮仍是蓝底蓝框。

「纯白像素 0 个」是最硬的判据：改之前整张图里一个白点都没有， 方块确实是不存在的；改之后方块是实打实的白色面。

为什么会长成这样

  • 错的那条规则是我自己加的：.avslot.off { background:#F5F5F7; border-color:transparent; }， 照「灰色 = 不可选」的通用直觉写，没对过色值。
  • 本页 .page 的底色就是 var(--parchment) = #F5F5F7 —— 和方块填充是同一个色值，再叠一个透明描边，边界两头都没了。
  • 原型 v151 里根本没有 .off 这条规则：未选中就是最基础的 .avslot （#FFF 底 + 1px #E1E3EA 描边 + 深色字）。也就是说「白卡浮在灰底上」 本来就是这页的区分方式，我多写了一条反而把区分抹掉了。
  • 修法是直接删掉那条覆盖，让未选中回到基础态 —— 没有新增任何色值。
  • 顺手加了守卫 scripts/verify-partner-availability-ui.js（14 项）：盯着「未选中必须是白底 + 非透明描边」， 并且全站扫一遍伙伴端 wxss，谁再写「羊皮纸色底 + 透明描边」就红。 （唯一例外是 review-detail 的 .preset，它嵌在白卡里，灰块配白卡是对的，已在脚本里写明理由。）
这份预览只是本地静态页，没有部署，没动线上。
