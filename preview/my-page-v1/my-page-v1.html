焦点从哪来
v8 的既定手法：深色卡 = 全页唯一主角（管理端年级卡、直播行都这么做）。用户卡从灰底升级为墨黑 Hero 后，页面第一次有了「先看哪」的答案；下方所有羊皮纸卡自动退为内容层，深浅对比本身就是层级，不需要加任何高亮色。
顺手解决一个信息问题
Hero 卡里加了一行四格统计：全部 / 待审核 / 已通过 / 已驳回。数据后端都有（list 接口的 status 分布，前端汇总即可，不用新接口）。待审核数用暖黄色点亮——它是学生最关心的数字；筛选胶囊的默认态和统计天然呼应。
改动的边界
只动「我的」页（mySubmit）的 wxml/wxss + js 里加一个 status 分布汇总（纯前端计算）；用户卡上会补充班级·学号一行（userInfo 里已有）；投稿列表、筛选交互、撤销、关于/退出全部保持现状。
确认后我做什么
改 mySubmit 的 wxml/wxss：深色 Hero 卡（含统计行）+ 未登录态同位置换成深色登录引导；segment / 列表 / 入口不动。js 只加几行汇总计算，接口零改动。
