v3 · 依据 skill `apple-design`（WWDC《Designing Fluid Interfaces》等）

形态不动，换的是手感和材质

结构沿用 v2（单页 + 筛选条件 —— 那是你要的），v3 改的是「怎么动、怎么分层」： 全部动效换成弹簧、反馈发生在按下那一刻、弹层能拖着关也能拖到一半反悔、 毛玻璃材料承担层级、排版按字号分字距。 而且这一版是能真点、能拖的原型，不是截图 —— skill 的原话是「一个可交互的 demo 顶一百万个静态稿」。

一、和 v2 的差别

维度v2（静态稿）v3（交互原型）
能不能用8 张截图，点了没反应真数据 + 真筛选：条件、级联、搜索、分页、批量、弹层全部可用，改名/停用/清理真的会改数据
动效CSS transition，固定时长，不可打断弹簧（阻尼 + 响应），任何时刻可被新输入改写目标值，不跳帧
反馈时机松手才生效按下即缩放（:active + 140ms 回弹），松手才提交
弹层只画了打开态就地展开（transform-origin 对准触发按钮）、可拖拽关闭、带速度交接与动量投影、向上拖有橡皮筋
层级 / 材质整片白色 + 1px 分隔线侧栏 = 重材料、顶栏 = 悬浮毛玻璃（内容从下面滚过去）、浮动条 = 薄材料；没有渐变
排版一套字距走天下字距随字号变（大字负字距、小字正字距），行高与字号反向，数字全部 tabular
可达性没处理prefers-reduced-motion / -transparency / -contrast 三个信号都接

二、apple-design 落地对照（可逐条在原型里验）

1
响应：把延迟砍到 0
搜索不做防抖，每敲一个字符同步重算（数据在内存里，没有理由等）；筛选条件点一下就生效， 没有「确认」这一步；按钮的按压反馈挂在 :active 上，不等 click。
3
可打断：动到一半能被抓住
所有弹簧都能在飞行中被 setTarget() 改写，并且从当前屏幕上的值继续（不是从目标值重来）。 试法：点开一个筛选条件，在它还没展开完时点另一个 —— 第一个会平滑收回，不卡顿。
4
弹簧：用阻尼 + 响应，不用时长
默认 阻尼 1.0 / 响应 0.35（临界阻尼、不过冲）； 只有手势带着动量时才给 0.8（弹层被甩出去的那一刻）—— 一个淡入的菜单不该过冲。
5·6
速度交接 + 动量投影
拖弹层松手时，把指针的瞬时速度当作弹簧初速（无接缝）， 并用 project(v, 0.998) 预测落点来决定「关掉还是弹回」—— 所以轻轻一甩就能关掉。
7
空间一致性：从哪来、回哪去
条件下拉/菜单的 transform-origin 对准触发它的那颗胶囊；弹层进入与退出走同一条路径； 尊重抓取偏移（抓到哪就从哪拖，不会跳到中心）。
9
橡皮筋：边界是软抵抗，不是硬停
弹层往上拖超出上限时，位移按 rubberband() 递减 —— 手感是「到头了」，不是「卡住了」。
12
材质与景深
侧栏最重（结构）、顶栏次之（悬浮）、浮动条最薄（交互）； 弹层是「模态」做法：scrim 变暗 + 父层后退 3.5% + 材料以 scale 0.93→1 成形。 打开弹层时顶栏的滚动加深效果会自动卸掉，避免叠两层景深。
14
减少动态 / 减少透明 / 加对比
三个 prefers-* 都接上了：减少动态时弹簧降级为 180ms 交叉淡入； 减少透明时毛玻璃全部变实底；加对比时补描边、深色卡转纯黑。系统设置里能直接验。
15
排版：字距跟着字号走
19/26/34px 用负字距（大字反而要收紧），11.5/12.5px 用正字距（小字要放开）， 行高与字号反向；优先系统字体（自带光学尺寸与字距表）。
16
简单 ≠ 极简；确认只给真正不可逆的
日常动作（改名、重置密码、停用）不弹二次确认，改成底部一条 toast + 可撤销； 只有毕业清理这种真不可逆的才上「输入年级」确认。

三、刻意没有照搬的地方（你的铁律优先）

① 不用渐变做滚动边缘
skill 建议「在固定 chrome 与内容交界处放一小段模糊/渐隐遮罩」。 但 v8 定死了无装饰性渐变，所以这里改用：内容直接滚到毛玻璃底下（本身就是最好的边缘效果） ＋ 滚动时给顶栏加一层无色投影。功能一样，不引入渐变。
② 强调色仍然只有一个
skill 里的示例会用材质和颜色自由发挥。这里仍守 v8：只有 #0066CC 一个强调色， 材料的差异全部靠透明度、模糊半径、投影深度做，不靠加色。深色卡回到主角位置 —— 页面最重的一条信息就是它。
③ 材料的模糊半径不逐帧改
skill 建议让 backdrop-filter 的模糊半径与 scale 一起长。 但全屏尺寸的 blur 每帧改半径是这个页面上最贵的一件事， 收益只是「更明显一点的材料感」。这里改成半径固定在 CSS 里， 到场感由 scale 0.93 → 1 承担 —— 观感几乎一样，帧预算省下来给手势。
另外：这一版没有引入任何第三方库（Motion / Framer 都没用），弹簧、投影、橡皮筋、FLIP 全部是 60 行不到的 requestAnimationFrame + 固定子步长积分，免得给这个项目加构建依赖。

四、怎么玩（原型里值得试的 8 件事）

级联「班级」在没选年级时是虚线禁用态，点它会告诉你要先选年级；选了年级再看它 —— 名单跟着换。
条件胶囊选中条件后下面出现一枚可摘的胶囊，点 ✕ 摘掉它，后面的胶囊会平滑挪位（FLIP，不是硬跳）。
弹层拖拽打开「名册导入」，抓住顶部的横条往下拖再松手 —— 拖得越远 / 甩得越快就越可能关掉； 往上拖会撞到软边界。松手后如果没关掉，它会自己弹回去。
中途反悔拖动中松手后立刻再抓住，动效会从当前位置继续，不会跳。
就地展开点「导入批次」弹层里的任意一行「筛选这批 →」：弹层关掉，筛选条上多出一枚批次胶囊，列表已筛好。
批量跟随范围勾选行后底部浮起一条批量条；不勾选时按钮文案是「重置这 N 个」，勾了就变成「选中的 N 个」。
顺手改数据表格里点「改名」，输入新名字保存 —— 列表会立刻更新（原型内的数据）。
不可逆才确认选中某个年级后，深色卡下方出现「整届操作」；点「毕业清理…」，得把年级名原样输入才能按下去。
地址栏那一行是实时的：每改一个条件都会同步进去（原型里用的是 # 哈希，因为 file:// 下推不了 history）。
