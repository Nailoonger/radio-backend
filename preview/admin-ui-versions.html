管理后台 UI 方案 · 版本对比

每一版方案都是独立、可单独打开的静态网页，旧版一律保留不删，方便对照着看改了哪里。

命名与存放规则

  • 一版一个文件夹：preview/admin-ui-v<版本号>/
  • 主文件与文件夹同名带版本号：admin-ui-v1.html、admin-ui-v2.html —— 两版同时打开时不会认错
  • 渲染图放在各自目录下的 shots/，文件名带版本前缀（如 v2-03-dashboard.png）
  • 新版本只新增目录，不改也不删旧目录
