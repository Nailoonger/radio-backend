伙伴端登录 · 复用学生端设计 v2

左＝学生端，右＝伙伴端。两边共用同一份样式（伙伴端 wxss 只有一行 @import "../../pages/login/login.wxss"）。v2 改动：学生端摘掉「微信一键登录」按钮、 伙伴端删掉副标题「用站内分配的伙伴账号进入」、账号提示改回与学生端一字不差。

怎么做的

  • wxml 照学生端结构逐块搬（顶栏 / 收音机线稿 / 玻璃卡 / 卡底注 / 灰字入口）。
  • wxss 只有一行 @import 引学生端那份 —— 不复制第二份，学生端以后改视觉伙伴端自动跟上。
  • 为什么不塞进 app.wxss 共用：全局已经有一个 .body（padding 0 40rpx）， 登录页的 .body 是 padding 12rpx 44rpx 0，塞进全局会把全站页面的 .body 顶掉。
  • js 一行登录逻辑都没动：方法名本来就对得上（inputUsername / inputPassword / togglePwd / doLogin / goBack / goStudentLogin / showLoginHelp）。
  • v2 学生端：删掉 .or-row（「或」分隔）与 button.ghost-btn（微信一键登录）， 连带删 .wx 绿点样式与 doLogin() 这个随之变死的方法。 app.login() 本体保留 —— pages/submit/submit.js 还在用。
  • v2 伙伴端：删副标题「用站内分配的伙伴账号进入」；账号字段回到「学号」， 占位符与学生端同一句（库里伙伴就是拿学号进的，不存在「伙伴账号」这种东西）。
  • 守卫补两条：学生端不许再出现微信入口连同 app.login() 调用； 伙伴端账号字段的标题与占位符必须与学生端逐字相等。
