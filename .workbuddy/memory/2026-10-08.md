## 新功能立项：可接收点歌日期（收歌窗口按「具体日期」控制）

**需求（陛下原话）**：「有时候节日的时候需要播放相关主题歌曲，所以想设置可接收点歌日期」
→ 澄清后收敛为：**提前一周把下一播出周的某一天关掉**，那天不收点歌（不是"多开几天"）。

**现有机制的两个事实（读源码确认，别凭印象）**
- `src/services/broadcastSlotService.js`：学生可选播出日期 = `for (let i=0;i<5;i++)` **写死的下一周周一~周五**，
  后台只能改「每天几点播」，**没有任何地方能关掉一整天** ← 这就是缺口，且是个小缺口。
- `src/services/songWindowService.js`：收歌窗口可配，但只认**「星期几 + 时刻」**（如 `每周六 18:00 → 周日 18:00`），
  **没有「日历上具体某一天」的概念**；窗口必须整体落在「点播周」内（保命硬约束）。
- ⇒ 这个需求和 `docs/specs/11-theme-broadcast`（周主题点歌）**无关**，11 是内容层、不碰日期。

**拍板的两个方向（待陛下否）**：① 粒度＝整天关（不是单场次）；② 学生端被关的那天**整组不出现**（不置灰、不标"暂停"）。

**产出**：`preview/slot-open-dates-v1/slot-open-dates-v1.html`（v1 静态预览，可点开关→学生端联动）
+ `_check.cjs`（自检：渐变 0 / 彩色投影 0 / 颜色全在 token 内 / JS 语法 2/2）+ `shots/v1.png`。

## 踩坑（跨平台搬样式）
⚠️ 把小程序 wxss 的 `scroll-view` 写法直接搬进 HTML 预览会**塌成 0 高**：
`.slot-sheet-body{flex:1 1 0; min-height:0; height:0}` —— `height:0` 是为小程序 scroll-view 显式给高的补丁，
在网页 flex 里（父容器高度 auto）会让内容整个塌掉。网页预览要改成 `flex:0 1 auto; min-height:0; overflow-y:auto`。
