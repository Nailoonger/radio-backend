## 最新口径（v25–v36，2026-10-12/15 陛下）
- **社干端＝五模块：工作台 / 审核 / 稿件 / 班表 / 我的**（角标 3/8/1/0/1）。
  工作台＝`homeTop()` 助手（通栏欢迎带 + 大白卡；**社干/超管不要「需要你处理」**）＋听众投稿·站内协作三联卡 + 考勤录入行；
  **稿件＝与站员同功能**（AI 找稿 + 继续写 + 我的稿件 + 版本 + 导出）；**班表＝`mgr-schedule`**（排班入口就在班表里）；
  **我的**＝互评 / 可排时间 / 请假进度 / **我的考勤（「本月 7 / 8 场 · 只看不录」——必须与「考勤录入」区分）** / 伙伴名册 + `.btn.block` 退出登录。
  ⚠️ **v32：社干/超管工作台不要「需要你处理」卡**（站员保留，`homeTop(...,noNeed=true)`）；**班表页＝一卡**（排班工作台/草稿与调整/人员轮值/发布记录/导出），伙伴名册入口只留在「我的」。
- **v42（更正 v41）**：**投影不许删**——那是"浮起来"的海拔。真正的问题是**被轮播 `overflow` 裁掉**（只在圆角缺口露一块灰）。做法：轮播改 **transform 轨道**（`translate3d(-i*100%)` + 索引制 `paintCar`）+ 容器 `padding:0 0 26px` 让投影落地；海拔定稿 `0 16px 28px -12px rgba(0,0,0,.28), 0 4px 10px -4px rgba(0,0,0,.12)`（判据：下沿 26px 内最暗 194、88% 像素比底色暗）。
  ⚠️ 判"元素错了"之前先判"是不是环境裁了它"。
- **v41**：`.float` 的 30% 黑装饰投影~~已删~~（v41 的错误结论，已由 v42 更正）（`box-shadow:none`）——它在轮播 `overflow` 容器里被裁掉大半，只在**卡片圆角缺口**露出，看着像两块脏灰。**设计系统不给卡片投装饰阴影**。
- **v40**：大白卡轮播＝**可鼠标拖 + 自动播**（`initCarousel()` 在 `renderPhone()` 末尾重绑）：pointer 拖动 1:1 跟手、松手吸附、`.dragging` 关吸附；4.2s 自动翻、按下即停、6s 后恢复；圆点可点；**拖完 400ms 内吞掉 click**（否则误进链接）。
  ⚠️ 隐藏滚动条 + 桌面鼠标 ⇒ overflow 容器**拖不动**（这就是「没法滑动」的根因）；headless 下 smooth 滚动不推进，审计里把 `Element.prototype.scrollTo` 改成立即赋值。
- **v39**：筛选／切换＝**`.chips`（各自独立的胶囊，不共槽）**——选中 `#1D1D1F`(=`--ink`) 实心白字、未选 `#E8E8ED` 实心灰字、gap 8、min-height 38；用于稿件筛选/审核三段/审核下级/留言筛选/值班时段周几。⚠️ 内容宽左对齐 ⇒ 右侧留白是设计（对齐审计里 `.chips` 不参与「填满」检查）。
- **v38**：① **值班时段按周几分设**——`S.slotsByDay[5]`（0=周一…4=周五，每天自己那几个/名称/时间）+ `S.day`，页内周一~周五 tabs；加/删/改名/改时间只作用于当天；站员「可排时间」每天读自己那天，**请假表单时段跟着所选日期走**。
  ② 排班 key 统一 `周几|时段`（`S.plan`）、人存 `S.assign['周几|时段|部门']`；
  ③ **加人 / 换人 / 撤下**：候选弹层只列「可排时间已确认」的人（有课的标灰）；人芯片＝名字（锁定）+ **⇄**（换人/撤下）。
  ⚠️⚠️ 新属性必须加进事件委托 `closest()` 白名单，否则**点了没反应**；`data-dept` 键从 2 段变 3 段（周几|时段|部门）记得同步解析。
- **v37**：① 值班时段＝**滚轮选择器**（点时间开底部弹层，时/分两列  可翻，取消/确定）+ **时段名 input 自定义**（不整体重渲染，免失焦）；

## 旧口径（v7/v8/v10 定案）
- **站员**：班表＝周表格（列周一~五带日期，行早会/午间/下午），**一个时段可多人**、一人一颗名字胶囊自带状态色（我·浅蓝/请假待批`#FDF3DC`/已批准`#EAF7EF`/空缺虚线）+ 图例。「当场反馈」已改名**互评**。⚠️ **不要权重**——排班顺序＝场次少的、最近没排的、上次值班更早的优先。
- **社干**：工作台＝听众投稿（点歌/文稿/留言）+ 站内协作（内部稿件/请假审批/岗位补位）+ 考勤录入/班表。
  ⚠️⚠️ **「按现有的 X 来做」＝去读真实文件**：**真实处理台 = `miniprogram/pages-admin/review-detail/`**，五段（队列导航 / 投稿人卡 / 内容+本周名额 / 驳回原因必填 5 预设+警示行 / 审核记录"没处理过就直说"），**四段不合并**；队列页待审条目右边直接带通过/驳回。考勤录入＝五天胶囊 + 人三态。伙伴名册＝导入/导出/勾选批量删，社干也写进名册。
- **超管**：具备社干全部功能 ⇒ **共享注册** `SCENES.push({…,role:'super'})` 批量复制（列表里**别带 `more`**）；工作台多「管理」块（账号/排班规则/考勤总览）；两区块＝**三联卡**（站员端是胶囊行）；**问候卡三个身份都要有**，判据 `grep -c "hi\">'+greet"` = **3**。

## 自检工具（每次改场景/样式都跑）
