## ⚠️ 抓到 1 个真 bug（只在成功路径上炸，测试不覆盖就上不了线）
`services/roster.js` 的 `commit()`：
```js
const batchId = await nextId(C.IMPORT_BATCH);
await insertOne(C.IMPORT_BATCH, { id: batchId, ... });            // _id = 'auto_7'
await updateById(C.IMPORT_BATCH, batchId, { created, updated });  // ❌ doc('1') 不存在 → 抛错
```
云文档 `_id` 是自动生成的字符串，`batchId` 是**数字业务主键**。`updateById` 走 `doc(_id)`
→ 抛 `document does not exist` → 整个 `commit` 变 50001。
**特征：写失败（40001/40901）的用例全绿，唯一没覆盖的就是「导入成功」那条。**
✅ 修：接住 `insertOne` 的返回值 `batchDocId`，用它更新。
**排查手法**（已写进 skill）：`grep -n "updateById(" | grep -v "_id"` —— 全项目 34 处只有这 1 处踩坑。
