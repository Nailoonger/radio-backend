# ③ 导出生产库：踩到「容器不认识 git pull 下来的新代码」

- 陛下在服务器跑 `docker exec -i radio-backend node cloud/migration/export.js`

- **根因**：容器用的是**构建那一刻的镜像快照** —— `git pull` 只更新磁盘文件，**不影响已运行的容器**。
  （顺带确认 `.dockerignore` **没有**排除 `cloud/`：它只排除 `*.md` / `docs` / `admin-web` / `miniprogram` 等。）
- **免 rebuild 的解法**（不重启服务、线上无感）：
  ```bash
  docker cp cloud/. radio-backend:/app/cloud
  docker exec -u root -i radio-backend node cloud/migration/export.js
  docker cp radio-backend:/app/cloud/migration/out ./cloud/migration/
  ```
  - ⚠️ 结尾的 `/.` 是 docker 的语义：只拷**目录内容**（写成 `cloud` 会在目标已存在时套成 `/app/cloud/cloud`）。
  - ⚠️ 必须 `-u root`：cp 进去的文件属 root，容器默认跑在 `app` 用户下**写不了 `out/`**。
