### 班表页四行卡高出 90px · 真凶是 `.sc-row` 少了 box-sizing（23:2x，`ed818d1`）
**现象**：班表页底部「排班工作台 / 人员轮值 / 发布记录 / 导出」四行卡比 v151 一整圈矮胖，行间距大。
**根因**：`.sc-row { min-height:119rpx; padding:25rpx 0 }` —— **WXSS 默认 content-box**，
`min-height` 只约束内容区，上下 padding **额外叠上去** ⇒ 每行 169rpx(84.5px)，而 v151 是 62px。
参数看着是"照抄 151 的 119rpx≈59.5px"，实际渲染差 22.5px/行。
**修**：`.sc-row` 加 `box-sizing:border-box`，min-height 124rpx(62px)、padding 26rpx 32rpx、gap 24rpx、
`border-bottom: 1px #F1F1F4` 末行无；`.sc-wrap` 去横向 padding；`.ts-bar` 去白底（151 是纯文字）。
**判据**：逐属性 diff 脚本（本页 rpx/2 vs v151 px）15 项全 OK；四行总高 4×62=248px。
⚠️ 铁律补充：**凡是「min-height / height + padding + border」的盒子，必须先确认 box-sizing**；
WXSS 不是 border-box，照抄 CSS 的 px 值但漏了 box-sizing 会静默变高（不报错，只是"看着不对"）。
