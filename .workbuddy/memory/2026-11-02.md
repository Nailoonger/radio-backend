## 管理端切角色不实时同步（21:5x 修，提交 400a21e）

陛下：「管理端 web 在账号管理那里切换账号角色的时候，无法做到实时同步，导致权限错乱」

**两层静默错**：
1. **角色是 JWT 的签发快照**。`requireAdmin` 直接信 `payload.role` ⇒ 降权的人旧 token 照样过
   `asSuper`（能改账号/开关/删数据）；升权的人永远按旧 role 跑，要等 7 天 token 过期。
2. **直连 update 只写两档**：`src/controllers/admin/adminController.js` 是 `[0,1].includes(req.body.role)`
   ⇒ **站员(2) 被静默丢弃**，界面提示保存成功、刷新还是原角色；也没 `Number()`，传字符串同样丢失。
   云端 `adminMgr` 一直是对的 —— 又一次「三档写满」铁律，这次漏在直连那份。

改法：
- 新增 `services/adminLive`(云) / `src/services/adminLiveService.js`(直连)：按 token id 查 admin 表，
  **role 以库为准**；查不到行返回 null（保持「存量 admin token 例外」）；**停用不在这里拦**（原来是 40301，改成 40101 = 改契约，本次不动）。
- 云端入口 `index.js` 注入 `ctx.adminLive`，`lib/auth.requireAdmin` 用它覆盖 `payload.role`
  ⇒ 45 处 asAdmin/asSuper 一行没改（当初把校验放入口的价值）。
- 直连 `adminAuth` 同口径覆盖 `req.admin.role`。
- 前端：`stores/auth.js#ensureFresh`（5s TTL + 并发去重）→ 路由守卫 await 它 → MainLayout 30 秒轮询 →
  Account.vue 改自己后 `fetchProfile()`。

顺带补洞：
- **最后一位超管不许降级**（原来只拦 remove、不拦 update ⇒ 唯一超管改自己 = 整站锁死）。
- 非法/空角色报 40001：`Number('') === 0` 会被算成超管。

校验：`test-admin-role-sync.js` 20 项（真路由+内存云库）挂 regression（4562/0，两轮）；
`verify-admin-role-sync.js` 12 项挂 verify 第 13 阶段（verify.test 12→13）；mini 13 段全绿；vite build 通过。
