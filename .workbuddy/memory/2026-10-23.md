## 伙伴端 v109（排班工作台整体重构，按陛下口述需求）
- 需求原文要点：四块（值班时段/排班工作台/班表草稿与调整/排班规则）合成**一个「排班工作台」**；
  社干·站员**只读**时段与规则，**只有超管能发布**；进页面先看**本周班表**，没有就显示「本周未排班」；
  按时段生成草稿 → 人工调整 → 校验 → 发布；**草稿底部小字一键清空**；可**固定某人某天某时段**（再次生成保留）；
  换人弹层按图 3；**值班时间代录**模块；发布后可**撤回**（撤回后历史仅超管可见、其他人看不到），撤回后回草稿。

### 落地
- **状态机** `S.sched={state:'none'|'draft'|'published'|'withdrawn', ver, at, by, checked, history[]}`；
  四种状态条：灰「本周未排班」/ 琥珀「草稿未发布（N 个空缺）」/ 深色「已发布 vN」/ 红「已撤回」。
- **本周班表区**：never 排 / 撤回 → 空态卡；draft / published → 复用 v107 课程表。
- **操作区按状态换**：未排班→生成班表草稿（时段没发则显示"去发布值班时段"）；
  草稿→再次生成 + 「检查并发布」（未校验时文案就是它，校验通过后变「确认发布」）+ **小字「一键清空班表」**；
  已发布→撤回发布 + 建立修订草稿。
- **简化无权重引擎 `genDraft(keepFixed)`**：先过滤（部门资格、该时段来不了、同场不兼两岗、每天最多 1 场），
  再按「本周场次少」挑人；`keepFixed` 时**只保留已固定的人**（`assign[key][i][1]===1`）。
  ⚠️ 「指导老师」强制跳过自动分配（只能手工指定）。
- **换人/固定弹层**（图 3）：标题「周三 10/8 日 · 午间 1」+ 副说明「12:10—12:30。手工换人也会检查同一组硬条件。」+
  「当前：xxx」+「固定当前人员/取消固定」+ 候选行「部门 · 本周 N 场 · 近 4 周 N 场 / N 分钟」+ 原因必填 + 保存。
  保存时**换人后自动设为固定**。
- **校验 → 发布**：校验要求时段已发布 + 零缺岗；`checked` 为真才允许发布；发布写 `S.sched.ver+1`、时间、
  历史，并同步 `S.week.published` / `S.shift.published`（工作台那张卡片跟着变）。
- **撤回**：state='withdrawn'，历史追加一条；`S.week/shift.published` 置 false；撤回后页脚提示历史只有超管能看。
- **值班时间代录**（新场景 `proxy`，tab=mgr-schedule）：选人胶囊 + 该人本周所有时段（勾＝可排）+ 必填原因 + 保存。
- **只读弹层**：社干/站员点「值班时段」「排班规则」→ `roSheet()`（只读列表，超管才有编辑入口）。
  `ro:` 前缀在 rows 里转成 `data-roview`，**不能塞进 data-go**（会把 scene 设成不存在的 ro-view）。
- 审计 **39/0**（四态、生成、校验拦截、发布 v1、撤回、历史、换人+自动固定、代录、只读、权限差异）；
  已发布，线上 title=v109 ✅
- ⚠️ 踩坑：`rows` 数组少一个元素 → `r[3].indexOf` 崩；替换大函数时**旧函数体残留**（`var steps=[` 之后那段）
  会变成函数外语句 → 必须按「下一个场景注释」定位删除，并用 `new Function` 做语法体检。
