## notice-hub-v5 · 密钥页旋转木马收尾（删圆点 + 根治横穿）

- 用户：删掉轮播下面的圆点进度条。已删 `.car-dots` CSS / HTML / JS 三处（`after()` 里 3 处 `dots` 死代码一并清掉，grep `carDots|car-dots|dots` = 0）。名称 `#carName` 是唯一指示。
- **横穿的真正机制（第三次踩，这次钉死）**：弧形轮播用 `d=((k-step)%N+N)%N; if(d>N/2)d-=N` 现场归一，
  N=6 时 d 的取值域是 [-2, 3]，**±3 是同一个槽（正后方），归一化在折返点上分不清"从左侧退场"还是"从右侧入列"**。
  后果：`park()` 固定送 `translateX(196px)` ⇒ 向左转时元素从 +196 滑到 -142，**横穿整屏**。
  ⇒ 改法（三件）：
  ① 每枚徽标用 `pos[]` **连续跟踪**位置（`d=pos[k]-(step-atStep)` 然后 while 折回 ±HALF），不再现场模运算；
  ② `park(el,side)` 按**它下一次入场的那一侧**送屏外（`side = ds>0?1:-1`），左右各一个停放位；
  ③ `goTo` 拆成**逐格 150ms** 走（一次一格），ds 恒为 ±1，不会一步跨过背面而没有中间帧。
- 探针 `_probe.html`（30ms×600 帧 + 每 5s 点最左徽标逼出后退路径）：`worstDx=0.00 横穿帧数=0 dots=0`。
  判据写法：只统计"相邻两帧都 opacity>0.02 且在屏内"的位移，屏外 park 的瞬移不会误判。
- 截图校验 700/2400/5000ms：中央徽标始终居中、两侧对称、无圆点。已发布，`/` 与 `/partner/` 均 200、`car-dots` 计数 0。
