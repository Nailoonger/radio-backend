## ⚠️ v1 被当面否掉：臆造界面 + 搞水印（v2 已重做）

**陛下原话**：「你都不去文件里面查看我现在的页面是什么样子的，你就乱做，给我重新做，
好好看看你同事 codex 做的，你别给我搞水印」。

**错在哪**
1. 我只读了 `pages/*/*.wxml` 就自己"简化设计"了一套界面示意 —— **源码 ≠ 渲染结果**，
   凭空捏了输入框/开关/列表，和真机差得很远（真 tabbar 是圆角胶囊 + 黑底选中项、
   登录页有收音机线条插画、"我的"未登录是白卡浮起 + "加入我们"行…我全都没有）。
   `preview/screens/*.png` 也**不能用**——那是旧版截图（旧 tabbar、"不收集手机号"、
   投稿页还是手填日期），与当前 WXML 冲突。
2. 每张图底部放了「站徽 + 菁菁校园情，悠悠广播声 + 页码」→ 被当成水印。**对外物料别放这堆。**

**v2 正确做法（可复用）**
- `preview/onboarding-v2/screens.html`：照 `app.wxss` + 各页 `*.wxss` **逐值 1:1 还原**成 HTML。
- ⚠️ **换算技巧**：`html{font-size:0.52px}`（1rpx = 0.52px，750rpx = 390px），
  下面所有尺寸直接写 rpx 数值（`34rem` 就是 34rpx），**不用手算 0.52**。
- 6 屏：首页 / 我的未登录 / 登录 / 设置新密码 / 投稿点歌 / 我的投稿记录。
  tabbar 用 `position:fixed`（absolute 会被超长内容推到屏幕外被裁）。
  `body{width:390px;overflow-x:hidden}` + `.screen{position:absolute}` 才不会横向溢出。
- 截图：`chrome --headless=new --force-device-scale-factor=2 --window-size=390,845` → 780×1690。
  ⚠️ `--screenshot` 只截视口，高度要自己给准；表单页内容长，用 845 会切掉"提交投稿"。
- 引导图版式 `preview/onboarding-v2/index.html`：1080×1560，卡片 `min-height`（**不能写死 height**，
  否则 flex 压不上，步骤文字被深色卡盖住）。支持 `#g1…#g5` 深链单张查看/导出。
- **无 logo、无口号、无页码**。步骤两列 + 蓝色编号 + 深色提示卡收尾。
