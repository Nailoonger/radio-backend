# 2026-10-09

## 「可接收点歌日期」落地完成（源 + 云 + 后台 + 学生端）

需求（2026-10-08 立项，10-09 陛下「开始吧」＝认可 v1 预览）：节日/活动当天要播专题，
**提前把下一播出周的某一天关掉**，那天不接收学生点歌。

### 设计（一行核心）
- 新增 KV **`song_slot_blackout`**（JSON 数组，存**具体日期** `["2026-10-14"]`）；
  `getSlots()` 生成格子时**整天跳过**被关的日期 → `isValidSlot()` 自动拒绝、学生端分组自动少一天。
- ⚠️ **`getSlots()` 改成「先算日期框架 frames，再剔格子生成 list」** —— 原来 `weekStart/weekEnd/rangeText`
  是从 `list[0]/list[last]` 推的，全关时 list 为空会把范围文案塌成空串。现在框架始终 5 天。
- 返回值**新增** `days`（5 天框架 + `closed`）、`closedDates`；`getAdminConfig()` 一并透出（后台读它）。
- 整体覆盖语义：`PUT /admin/submit/slot-dates {closedDates:[...]}`，空数组 = 全部恢复。
