## push：本机确认无解（再查一遍）

陛下说「直接 push 吧」→ 实测仍失败：`fatal: unable to get password from user`（拿不到凭据）。
本轮把可能性都排掉了：

- `credential.helper` = `helper-selector`（GCM），但**没有任何已存凭据**：
  `~/.git-credentials`、`~/.netrc`、`~/_netrc` **都不存在**；环境里也没有 `GITHUB_TOKEN` / `GH_TOKEN` / `GIT_ASKPASS`。
- **`gh` CLI 未安装**（`gh: command not found`）⇒ 借 gh 的 token 也走不通。
- 网络本身是通的（`curl https://github.com` → 200，但慢，约 12s）。

⇒ **结论不变：push 只能陛下在自己终端敲**（会弹 GCM 登录窗口，登录一次即缓存）。
判据：`git status -sb` 里**没有 `ahead N`**。
