## 人工指派口径改判：允许强制超卖（01:05，提交 85a61f8）

陛下问「人工指派是强制的吗为啥不可以派到非首选时段」。**问的前提是误判**：非首选格可以派，
一格都选不了是因为**五格全满**（2/2 × 5）。但顺着查出**真漏洞**：

```js
disabled: !!s.full && !isPreferred     // 原代码
```
本意是「这条本来就占着这格 ⇒ 重选=回到原位 ⇒ 不该灰」，写成了「这格是不是他的**首选**」。
而人在候补（`scheduledSlot = null`）时**首选 ≠ 占位** ⇒ 首选那格 2/2 仍可点可存，
后端 `scheduling.js#manualAssign` **只校验 slot 属于可选周、不校验容量** ⇒ 直接落 3/2。
**这就是之前周一 3/2 超卖的路径**，不是"数据过期"那么简单。

陛下拍板：**管理员可以强制超卖**（不是「满格一律不能派」）。
改动（`admin-web/src/views/SubmitList.vue`，前端单文件，后端一行没动）：
- `assignOptions` 删 `disabled`，加 `full`；满格可点、虚线边 + 数字标红
- 新增 `assignTarget` / `assignTargetFull`，选中满格时底部压一条红底警告「会变成 3/2」
- `saveAssign` 满格走 `ElMessageBox.confirm('强制指派（超卖）')` 二次确认
- 文案改成「已满的格子也能选，会超卖、记 MANUAL、矩阵标红」
- `.slotbtn.selected` 从 `var(--ink)` 深色实心改成 `var(--accent)`（铁律：不自造深色件）
