### 追加：用户指出色板渲染崩了 → 出 v2 重修版（`preview/admin-ui-v2/`）

用户截图反馈「色板」整块糊掉，要求删掉 v1 重做。v1 目录已删，重修为 **v2**。

**真正的原因（三层，截图看不出来，靠脚本扫出来的）**：

1. **CSS 类名撞名**：色板和「开关」组件都叫 `.sw`。后写的色板规则只覆盖了 `display/flex-direction/gap`，
   开关的 `width:44px / height:26px / position:relative` 全部残留，`::after` 白圆钮也渲染进每个色块；
   容器只有 26px 高，48px 的色块被 `flex-shrink` 压成 **0 高**（实测 `barH: 0px`）。
   → 色板改名 `.swatch`，并给色块加 `flex:none` 兜底。修后 `barH: 48px`、`::after: none`。
   **教训：单文件设计稿（几十屏共用一套 class）改名前必须先扫类名，别靠眼睛。**
2. **类名根本没定义**：HTML 里用了 `gap10` / `gap11`，CSS 里压根没有 → gap 静默变 0，
   账号表格头像和姓名贴在一起。已并入阶梯值 `gap13`。
3. **间距口径自己没兑现**：文档写「卡内 13，区块 22~26」，实现里却有 9/10/11/12/14/16/20/22/24。
   已全部对齐阶梯 `4/8/13/18/26/34`；4 列成员网格宽度跟着从 `calc((100% - 42px)/4)` 改成 `-39px`。

顺带：色板「用途」那行原来用 `--soft`（白底 1.7:1）几乎看不见 → 改 `--muted-2`；
20 个色值加了 3 个分组标题（中性色 / 深色与强调 / 状态语义色），横跨整行（`grid-column:1/-1`）。
14 个页签压缩到 1440px 宽可一次放全。

**验证结果**：类名冲突扫描只剩 `基础规则 + .on 修饰符` 这类正常项、未定义类 0 个；
12 屏画布 `overY/overX` 全为 0（无溢出）；14 张截图全部重渲。

**沉淀**：把「类名撞名 / 未定义类扫描脚本」+「长页先量高度再设视口」两节写进了
`~/.workbuddy/skills/web-ui-screenshot-verify/SKILL.md`，下次做单文件设计稿直接复用。
