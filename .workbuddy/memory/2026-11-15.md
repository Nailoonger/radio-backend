### ⚠️ 发布链路与触发器的边界（**别推翻，是有意设计**）
`scripts/release/cloud.js:74-75` 的注释写明：
> Code releases preserve the actual trigger set, **including an empty set**.
> A repository config file is not authority to create or require a production timer.

⇒ **CI 刻意不管触发器**（`updateFunctionCode` 只更代码，造不出触发器）。
⚠️ 所以**不能**把它改成「Triggers 为空就 fail」—— 那会让 CI 永久红灯、挡住正常发布。
✅ 本轮改成**醒目告警**（不 fail）：线上触发器为空时打印三行修复指引。
⇒ 推论：**先 CLI 部署 / 控制台建触发器，再 push**；否则 CI 只是发版、不会补建触发器。
